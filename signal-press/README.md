# Signal press

An independent, original study in curved engraving, ASCII interference, and concentrated ultramarine, inspired by [Plastic Labs' Neuromancer](https://plasticlabs.ai/neuromancer) and [Nous Research's Hermes](https://hermes-agent.nousresearch.com). No affiliation with either project.

Open `index.html` directly in a browser. No dependencies, network requests, or server are required. The plate controls switch between engraved, ASCII, and mixed representations, adjust ink density, change the plate ground, and opt into subtle motion. Light and dark appearance follow the operating system; the appearance selector allows a local preview of either theme. Reduced motion overrides animation.

See [analysis.md](analysis.md) for the transferable styling recipe and [the comparative reference notes](../docs/neuromancer-hermes.md) for research.

## Assets and provenance

`specimen.svg` is an original code-generated vector engraving made for this experiment. The HTML embeds the same source so it remains self-contained; the standalone SVG is a small intentional asset for the collection index. All text, geometry, and code are original. There are no copied reference images, logos, fonts, or third-party code. No binary assets or generated build output are required. Root `.gitignore` already covers local tooling, dependencies, caches, and test outputs; no additional ignore rules are needed.
