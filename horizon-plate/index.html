How the plate is made

  
    
    
  1. Luminance. The source is drawn to the plate's exact device-pixel size, cropped with the anchor, and reduced to Rec. 709 luminance.
    2. 
    
  2. Tone. Auto-levels on the 0.5 / 99.5 percentiles, contrast, then polarity: which end of the range takes ink. The ink floor drops faint ink to zero, so the sky meets the page colour exactly. The dissolve multiplies ink by a ramp, so dots and lines thin out instead of fading in opacity.
    3. 
    
  3. Mark-making. Line fields and screens run at full resolution with one pixel of analytic antialiasing. Dithers run on their own dot grid, one cell per dot.
    4. 
    
  4. Quantize and encode. Coverage becomes 2 to 256 levels in an indexed PNG. Every palette entry is the ink colour, and transparency carries the coverage, so the file works as a CSS mask and as a plain image.
    5. 
    
  5. Ink with CSS. The page paints background: var(--ink) through mask-image. Changing the theme recolours the plate without re-rendering it. Dithers are scaled up with image-rendering: pixelated, so a 1-bit file at a quarter of the pixels stays sharp.
    6. 
  

  

    
Rules that keep it fast

    
    
      
  • Render once, offline or in this lab. The shipped page runs no script for the plate.
    • 
      
  • Never use background-attachment: fixed or a live filter on the plate. Both repaint on scroll.
    • 
      
  • Ship dithers at their dot grid and let the GPU scale them. Ship lines at 2× and let them scale smoothly.
    • 
      
  • Keep dither dots at a fixed CSS size: crop the plate on narrow screens rather than resizing it, or the grain beats against the pixel grid.
    • 
      
  • Lazy work is free: a footer is below the fold, so content-visibility: auto keeps it out of first paint.
