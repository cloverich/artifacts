02 / THE CEL RECIPE
Same shape.
Different light.
Cel shading turns a continuous light response into a few flat bands. Outlines are a separate layer. Neither effect comes from the animation engine.
CONTINUOUSQUANTIZED
light = max(0, dot(normal, direction))
band  = round(light × (N − 1)) / (N − 1)
color = base × (0.22 + 0.78 × band)
Canvas 2D computes an analytic sphere here. Vesper uses mesh normals and a custom four-step WebGL shader. Its thresholds differ from this evenly spaced teaching ramp.
